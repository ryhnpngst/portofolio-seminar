# CodeMonitor: Platform Praktik dan Monitoring Pemrograman Berbasis Web

## 1. Latar Belakang

Pembelajaran Informatika di SMK, khususnya materi algoritma dan pemrograman, membutuhkan kegiatan praktik agar murid dapat menerapkan konsep yang telah dipelajari. Namun, dalam pelaksanaannya, guru menghadapi tantangan untuk memantau proses praktik seluruh murid secara bersamaan. Dengan jumlah 36 murid dalam satu kelas, guru perlu membagi perhatian untuk memeriksa kode, mengetahui perkembangan pekerjaan, dan membantu murid yang mengalami kesulitan.

Apabila setiap murid menggunakan aplikasi pemrograman secara terpisah, guru perlu memeriksa pekerjaan satu per satu untuk mengetahui perkembangan praktik mereka. Kondisi ini dapat membuat proses pemantauan kurang efisien dan menyulitkan guru dalam menentukan murid yang membutuhkan pendampingan.

Berdasarkan permasalahan tersebut, dikembangkan gagasan **CodeMonitor**, sebuah platform berbasis web yang mengintegrasikan aktivitas praktik pemrograman dengan fitur monitoring untuk membantu guru memantau perkembangan pekerjaan murid secara lebih terpusat.

## 2. Mengenal CodeMonitor

**CodeMonitor** merupakan rancangan platform praktik dan monitoring pemrograman berbasis web yang ditujukan untuk mendukung pembelajaran Informatika di SMK. Platform ini dirancang agar murid dapat mengerjakan latihan pemrograman dalam satu lingkungan kerja, sementara guru dapat memantau status aktivitas dan melihat kode terbaru yang dikerjakan murid.

CodeMonitor dirancang untuk mendukung praktik Python serta penulisan kode Arduino/C++. Pada praktik Python, murid direncanakan dapat menjalankan kode dan melihat hasil eksekusi secara langsung melalui browser. Sementara itu, kode Arduino/C++ dapat ditulis dan dipantau melalui platform, sedangkan proses kompilasi dan pengunggahan kode ke perangkat keras tetap menggunakan Arduino IDE.

Pengembangan CodeMonitor berfokus pada kemudahan pemantauan proses praktik, bukan sekadar pengumpulan hasil akhir. Dengan demikian, guru diharapkan dapat lebih mudah mengidentifikasi murid yang belum memulai pekerjaan atau yang berpotensi membutuhkan bantuan selama pembelajaran berlangsung.

Saat ini, CodeMonitor masih berada dalam tahap perancangan dan pengembangan prototipe.

## 3. Fitur CodeMonitor

### A. Pengelolaan Kelas dan Praktik

Guru dapat membuat kelas, menyiapkan sesi praktik, dan memberikan instruksi tugas pemrograman kepada murid.

### B. Editor Kode Berbasis Web

Murid dapat menulis dan mengedit kode pemrograman melalui editor yang dirancang untuk mendukung Python dan Arduino/C++.

### C. Penyimpanan Kode Otomatis

Kode murid direncanakan tersimpan secara otomatis selama proses pengerjaan sehingga perkembangan pekerjaan dapat tercatat tanpa harus menyimpan secara manual setiap kali melakukan perubahan.

### D. Eksekusi Kode Python

Murid direncanakan dapat menjalankan program Python langsung melalui browser serta melihat output dan pesan kesalahan untuk membantu proses pengujian dan perbaikan kode.

### E. Dashboard Monitoring Guru

Guru dapat memantau status praktik murid melalui satu dashboard, termasuk murid yang belum mulai, sedang mengerjakan, tidak menunjukkan aktivitas dalam periode tertentu, atau telah mengumpulkan tugas.

### F. Pemantauan Kode Murid

Guru dapat memilih murid untuk melihat kode terbaru yang sedang dikerjakan. Setiap murid dirancang hanya dapat mengakses kode miliknya sendiri sehingga privasi pekerjaan tetap terjaga.

### G. Pengumpulan Tugas

Murid dapat mengumpulkan kode melalui platform setelah menyelesaikan latihan. Guru kemudian dapat memeriksa hasil pekerjaan tanpa harus mengumpulkan berkas dari berbagai aplikasi.

Melalui pengembangan fitur-fitur tersebut, CodeMonitor diharapkan menjadi solusi pendukung pembelajaran pemrograman yang membantu guru melakukan pemantauan dan pendampingan secara lebih efisien. Kebermanfaatannya akan dievaluasi setelah prototipe diuji dalam kegiatan pembelajaran.
